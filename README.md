## Webinar Description

As AI agents take on longer, multi-step engineering workflows, small errors no longer stay small. They compound across steps and quietly erode the ROI of your AI tooling. This interactive webinar will focus on how coding agents actually work under the hood, and the practical techniques that keep agent output accurate and reliable across complex workflows, so that quality, not token spend, drives your results.

### Topics

- How LLMs, agents, and context windows work: stateless models, token flow, recency bias, and
context rot
- Choosing the right model tier for each task and providing only relevant context
- Structuring work as research, plan, implement to avoid compounding mistakes
- Setting up deterministic guardrails such as tests and linters
- Persistent instructions, custom agents, skills, MCPs, and subagents
- Power-user tips including CLI tooling, collapsing tool calls, and /chronicle analytics
